# Destacar texto con negritas

Crea una página web con el título:

**"Destacar texto con negritas"**

Debe contener un `h1` con el texto:

**"Texto en negrita"**

Luego, un párrafo en el que la palabra **"Sevilla"** debe aparecer en negrita, seguido de una breve descripción:

```plaintext
Sevilla
Sevilla es la capital de Andalucía. Está atravesada por el río Guadalquivir y es famosa por la Feria de Abril, entre otros atractivos.
```
