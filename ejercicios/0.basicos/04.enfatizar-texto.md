# Enfatizar texto

Crea una página con el título:

**"Enfatizar texto"**

Debe contener un `h1` con el texto:

**"Enfatizados y cursivas"**

El cuerpo del documento debe incluir los siguientes párrafos:

```plaintext
Enfatizar un texto visualmente es ponerlo en cursiva o itálica, es decir, que la fuente aparece algo inclinada.

Visualmente es lo mismo itálica que enfatizado, pero HTML5 sólo da significado semántico al enfatizado.
```

Usa las etiquetas HTML adecuadas para **itálica (`<i>`) y énfasis (`<em>`)**.
