# Mis primeros enlaces

Crea una página con el título:

**"Mis primeros enlaces"**

Debe contener un `h1` con el texto:

**"Enlaces a secciones"**

El cuerpo debe incluir una lista con tres enlaces a las siguientes URLs:

- **[Etiquetas de formato](/etiquetas-formato.htm)**
- **[Sección head](/head.htm)**
- **[Sección Body](/body-html5.htm)**

Asegúrate de que los enlaces funcionan correctamente y crea los archivos necesarios.
