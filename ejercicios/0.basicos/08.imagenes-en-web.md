# Pon una imagen en tu web

Crea una página con el título:

**"Pon una imagen en tu web"**

Debe contener un `h1` subrayado con el texto:

**"Mi primera imagen web"**

Debajo, un párrafo con una imagen. La imagen está en la carpeta `imgs` con el nombre:

**`arboles.png`**

El atributo `alt` debe contener la descripción:

*"Árboles verdes"*

**Nota**: Asegúrate de usar una URL válida en tu entorno local para evitar errores de carga.
