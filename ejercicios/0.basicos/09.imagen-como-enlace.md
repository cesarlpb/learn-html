# Una imagen para un link

Crea una página con el título:

**"Una imagen para un link"**

Debe contener un `h1` con el texto:

**"Links e imágenes"**

Luego, en un párrafo, incluye un enlace en el que la imagen sirva como ancla. La imagen está en la carpeta `imgs` y se llama:

**`flecha-link.png`**

El enlace debe apuntar a la página de ejercicios.

**Nota**: En tu entorno local, usa una imagen existente para evitar errores de carga.
