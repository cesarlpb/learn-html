# Precios de alojamiento

Crea una página con el título:

**"Precios de alojamiento"**

Debe contener un `h1` con el texto:

**"Nuestros planes"**

Debajo, un `h3` con el texto:

**"Lista de precios"**

Luego, una tabla con tres columnas:

| Nombre    | Capacidad  | Precio |
|-----------|-----------|--------|
| Básico    | 1000 Mb   | 50€    |
| Personal  | 2000 Mb   | 75€    |
| Comercial | 6000 Mb   | 250€   |

Cada columna debe tener su encabezado (`<th>`) correspondiente.
